# backoffice-verla-mvp

Backoffice de VERLA para la organización: aliados, ofertas y catálogos.

## Stack

Next.js App Router, TypeScript, MongoDB con Mongoose y autenticación JWT.

## Scripts

- `npm run dev` — desarrollo
- `npm run build` — build de producción
- `npm start` — servidor de producción

## Variables de entorno

Configura MongoDB, JWT y las credenciales de servicios externos en `.env.local`.
No se versionan archivos `.env*`.
